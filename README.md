# InfiniteTalk for RunPod Serverless

[한국어 README 보기](README_kr.md)  

This project is a template designed to deploy and use [InfiniteTalk](https://github.com/Kijai/InfiniteTalk) in the RunPod Serverless environment. InfiniteTalk is an AI model that takes a single portrait image and speech audio as input to generate natural lip-sync videos with infinite talking capabilities.
